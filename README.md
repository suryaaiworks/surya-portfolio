# B. Surya Sai Teja — Portfolio

A one-page portfolio built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- Your uploaded photo is used as-is at `public/images/profile.png` — it is not regenerated or replaced anywhere.
- Add your real resume PDF at `public/resume.pdf` so the "Download Resume" button works.
- Update the placeholder links (GitHub, LinkedIn, email) in `components/Hero.tsx` and `components/Contact.tsx` with your real profiles.
- Colors, type scale, and layout follow the design brief: royal blue on white/slate, Sora for display type, Inter for body, JetBrains Mono for labels and tech badges.

## Build for production

```bash
npm run build
npm start
```
